# Mathematical Modelling of Cervical Cancer 

This repository contains a mathematical model to study the dynamics of **cervical cancer progression** caused by persistent **HPV (Human Papillomavirus) infection**. The project was developed as part of an academic research initiative at IIIT Kalyani.

## 📌 Overview

Cervical cancer is one of the leading causes of cancer-related deaths among women globally. This project formulates and analyzes a **compartmental differential equation model** that simulates the transmission of HPV and its progression to cervical cancer. The model includes four compartments:

* **S**: Susceptible individuals
* **I**: Infected with HPV
* **C**: Individuals with cervical cancer
* **R**: Recovered individuals

The model incorporates key epidemiological parameters and applies **next-generation matrix methods** to compute the basic reproduction number $R_0$, followed by **stability analysis**, **bifurcation analysis**, **sensitivity analysis**, and **numerical simulations**.

## ⚙️ Tools and Technologies

* **MATLAB**

## 🔬 Key Findings

* **$R_0 < 1$**: Disease-free equilibrium is stable → Infection dies out
* **$R_0 > 1$**: Endemic equilibrium is stable → Infection persists
* **Sensitivity analysis** indicates transmission rate (β) and recruitment rate (Λ) are the most impactful parameters
